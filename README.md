# Bayse Markets Dark Mode

An unofficial Android WebView wrapper for Bayse Markets.

## Features

- Universal dark mode
- Sun and Moon theme toggle
- Saved theme preferences
- Original Bayse launcher icon
- Dark navigation and menus
- Persistent WebView sessions
- Offline retry support
- Android 16 compatibility tested by the project owner
